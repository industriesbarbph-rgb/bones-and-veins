# Cure policy

1. DETECT automatically.
2. DIAGNOSE automatically.
3. PREPARE CURE only as a proposed action.
4. USER APPROVES CURE.
5. SOURCE CHANGE may occur only through a secure source gateway and only for the approved fault.
6. VALIDATE the staged repair.
7. USER APPROVES PUBLISH separately.
8. PUBLISH.
9. VERIFY live result.
10. WRITE ledger/report.

No cure approval implies permission to publish. No monitoring event implies permission to change a product.
